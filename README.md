# 빵을그리다(주) 판매이익 분석

이카운트 「판매현황」 엑셀을 매주 올리면 일·주·월·거래처·품목별 **매출 · 원가 · 판매이익**을 보고,
주간·월간 보고서를 만들고, 전표 입력 실수 가능성을 점검합니다.

- `index.html` — 화면 (깃허브 페이지로 열림)
- `sales_server.gs` — 구글 시트 저장소 (구글 Apps Script)

## 자료는 어디에 저장되나요?

판매 자료는 **직접 만든 구글 시트(내 구글 드라이브)에만** 저장됩니다.
이 저장소에는 화면 코드만 있고 판매·원가·거래처 자료는 들어 있지 않습니다.
화면에서 구글 시트에 연결할 때 **비밀번호**가 필요하며, 비밀번호가 없으면 웹 앱 주소를 알아도 자료를 읽거나 바꿀 수 없습니다.

## 처음 한 번 설치

1. 구글 드라이브 → 새로 만들기 → 구글 스프레드시트 (이름 예: 판매이익 자료)
2. 그 시트에서 **확장 프로그램 → Apps Script**
3. 원래 코드를 지우고 `sales_server.gs` 내용을 붙여넣고 저장
4. **배포 → 새 배포** → 유형 「웹 앱」, 실행 「나」, 액세스 권한 「모든 사용자」 → 배포 → 권한 허용
5. 판매이익 분석 화면 → 「연결 설정」에 웹 앱 주소를 넣고 비밀번호를 정해 연결

다른 기기(대표님 휴대폰 등)에서는 같은 주소·비밀번호로 연결만 하면 같은 자료가 보입니다.

## 매주

이카운트 → 영업관리 → 판매현황 → 지난주 월~일, 집계 기준 「일별 · 거래처별 · 품목별」 → 엑셀 내려받기 → 「자료 올리기」.
집계 항목에 「비고(적요)」도 넣으면 교환·샘플로 따로 적은 줄이 합쳐지지 않고, 비고에 「교환」이 있으면 자동으로 교환으로 분류됩니다.
같은 기간을 다시 올리면 그 기간 자료가 새 파일로 바뀝니다 (겹치지 않음).
